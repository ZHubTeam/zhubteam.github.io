🧠 How to Use ZHub

  1. Open your preferred Roblox exploit or executor (e.g., Synapse X, KRNL, Fluxus).
  2. Join any Roblox game.
  3. Open the executor console (usually a textbox window inside your executor).
  4. Paste the following code into the console:
    5. loadstring(game:HttpGet("https://raw.githubusercontent.com/ZHubTeam/zhubteam.github.io/main/zhub-script.lua"))()
  5. Press the Execute button.
  6. ✅ Done! ZHub will appear with a loading screen and then show the UI.

Note: Replace YOURUSERNAME/YOURREPO with your actual GitHub username and repo path where the script is hosted.
