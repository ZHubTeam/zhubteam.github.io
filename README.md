# ZHub - Roblox Script Hub

> ⚠️ Educational Use Only — Use at Your Own Risk

ZHub is a modern and clean Roblox script hub created for **educational and fun scripting exploration**. It is **not intended** for malicious use, game-breaking behavior, or to give unauthorized access in Roblox games.

## ✨ Features

- 🌙 Dark-themed UI with smooth rounded design
- 📁 Tabbed interface for scripts
- 🔍 ESP (highlight players)
- 🕊️ Fly script (toggle with `E`)
- ✅ No key system – plug and play
- 🔌 Supports executors: Synapse X, KRNL, Fluxus, etc.

## Installation
Paste the following code into the console:
  ```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/ZHubTeam/zhubteam.github.io/main/zhub-script.lua"))()
```

This hub was developed to demonstrate:
